# Contributing to the Authorship Reasoning License Project

Thank you for your interest in contributing! We're building a shared foundation for modular reasoning layers in AI.

## 🧠 What Can You Contribute?

You can contribute:

- New reasoning modules (prompt chains, logic adapters, symbolic scaffolds)
- Improvements to licensing structure
- Integrations with open-source LLMs (e.g., LLaMA, Mistral, GPT-J)

## ✅ Sign Your Commits

We follow the **Developer Certificate of Origin (DCO)**. All commits must be signed off using:

```bash
git commit -s -m "Your message"
```

This certifies that you have the right to contribute the content and agree to the license.

## 📦 Submitting Reasoning Modules

1. Fork the repo and create a folder under `/examples/your_module_name/`
2. Include:
   - `README.md`
   - `metadata.yaml`
   - `prompts.yaml`
   - `evaluation.md`
3. Open a pull request with the title:
   `[Submission] Reasoning Module – Your Title`
